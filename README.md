<h2> 🔖 Sobre:</h2>
Projeto de Nivelamento<a href="https://www.intuitivecare.com"> Intuitive Care</a>, uma atividade  de extração de dados, manipulação, modificação e conversão de dados em tabela.

<p>

<h2>🗂 Como baixar o projeto</h2>

    # Clonar o repositório
    $ git clone https://github.com/lorenzotrindade/Python_1

    # Entrar no diretório
    $ cd Python_1

    # Instalar as dependências
    $ yarn install

    # Iniciar o projeto
    $ yarn start
